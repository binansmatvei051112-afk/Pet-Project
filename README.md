# Портфолио разработчика: Матвей

Привет! Я начинающий Fullstack-разработчик. Создаю приложения на стыке фронтенда (Vanilla JS) и бэкенда (Python/FastAPI).

## 🛠 Стек технологий
* **Frontend:** HTML5, CSS3 (Glassmorphism, Grid/Flexbox), Vanilla JS.
* **Backend:** Python, FastAPI, MySQL, SQLAlchemy, ORM.
* **Tools:** Git, VS Code, Linux (Terminal), OpenCV (Computer Vision).

## 🚀 Основные проекты

### 1. HackDoc
Автоматизация генерации документов DOCX на основе данных из форм.
* **Стек:** FastAPI, Python, Tailwind CSS.

### 2. CryptoTracker
Сервис мониторинга портфеля с использованием внешних API и кэшированием запросов.
* **Стек:** FastAPI, SQLite, CoinGecko API.

### 3. Visual Pipeline (OMK)
Система компьютерного зрения для производства.
* **Стек:** YOLO, OpenCV, Python.
